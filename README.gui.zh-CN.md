## 1. 工具简介

dirscan GUI 是命令行版 `dirscan.exe` 的图形化外壳，二者共用同一套扫描内核（`dirscan` crate），能力一致：

| 特性       | 说明                                                         |
| ---------- | ------------------------------------------------------------ |
| 字典驱动   | 从字典文件读取路径列表逐一探测                               |
| 异步并发   | 基于 tokio 运行时，多 worker 动态取任务，自动负载均衡        |
| 实时着色   | 每条结果按状态码类别着色（2xx 绿 / 3xx 青 / 4xx 黄 / 5xx 红 / ERR 紫） |
| 状态码过滤 | 「仅显示」+「排除」双字段，排除优先（语法与 CLI 完全一致）   |
| 身份伪装   | 多 UA 轮换、Cookie 携带、HTTP Basic 认证                     |
| 代理支持   | HTTP / HTTPS / SOCKS5 代理（多代理轮换、内嵌认证、绕过列表） |
| 重定向递归 | 同源跳转自动入队扫描，严格去重                                |
| `%EXT%` 展开 | 字典中的占位符自动按扩展名列表展开为多条请求（内置 22+ 常见后缀，亦可外部文件自定义） |
| 速度可控   | 通过并发数、超时、重试调节                                   |

**GUI 相比 CLI 的额外优势：**

- 表单化输入，无需记参数；
- 支持「浏览」按钮选择字典 / 代理列表 / 扩展名文件；
- 日志区自动滚动，扫描进行中可随时停止；
- 结果按颜色分类，便于肉眼快速定位。

## 3. 快速上手

1. 双击 `dirscan-gui.exe`（Windows 64 位，无需安装依赖）。
2. 填 **目标 URL**（如 `https://example.com/`）。
3. 点字典行的 **`…`** 按钮，选择字典文件（例如仓库自带的 `wordlist.txt`）。
4. 点 **`▶ 开始`**。
5. 输出区实时滚动，结束时最后两行为统计汇总。
6. 需要中止扫描时点 **`■ 停止`**（任务优雅取消，已完成部分仍计入统计）。

## 4. 字段说明

| 字段       | 默认值        | 说明                                                         |
| ---------- | ------------- | ------------------------------------------------------------ |
| 目标 URL   | （必填）      | 基础 URL，`http://` 或 `https://`；末尾带或不带 `/` 均可，工具自动规范 |
| 字典       | （必填）      | 字典文件路径，每行一个路径；`#` 开头为注释；可用 `…` 按钮浏览 |
| 并发       | `10`          | 并发任务数（对应 CLI `-t`）                                  |
| 超时       | `10` 秒       | 单个请求超时（对应 `-T`）                                     |
| 重试       | `1`           | 请求失败时的重试次数（对应 `-r`）                             |
| 仅显示     | （空 = 全部） | 只显示匹配的状态码，逗号分隔，支持区间（对应 `-f`）           |
| 排除       | （空 = 无）   | 不显示匹配的状态码，语法同「仅显示」；可与「仅显示」组合，**排除优先**（对应 `-e`） |

**状态码过滤示例：**

| 输入           | 效果                                   |
| -------------- | -------------------------------------- |
| `200`          | 只显示 200 OK                          |
| `200,301,403`  | 只显示这三种精确状态码                 |
| `200-299`      | 只显示 2xx                             |
| `200-499`      | 只显示 2xx~4xx                         |
| `404,500-599`  | 在「排除」栏输入：隐藏 404 与 5xx      |

> 过滤/排除**只影响显示，不影响扫描**：被隐藏的路径仍会被请求、计数；同源重定向目标也仍会自动入队跟进。

## 5. 高级选项

点开「高级选项」折叠面板后可见：

| 字段         | 示例                                                | 说明                                                         |
| ------------ | --------------------------------------------------- | ------------------------------------------------------------ |
| User-Agent   | `Mozilla/5.0 ...` 或 `UA1,UA2,UA3`                  | 留空默认 `dirscan/0.1`；**逗号分隔多个 → 请求间轮换**        |
| Cookie       | `SESSION=abc` 或 `SESSION=abc; TOKEN=xyz`           | 分号拼接合并为一个 Cookie 头；可用来携带登录态               |
| Basic 认证   | `user:pass`                                         | 生效时所有请求都带 `Authorization` 头                        |
| 代理         | `http://127.0.0.1:8080` 或 `socks5://10.0.0.2:1080` | 支持 `http://` `https://` `socks5://` `socks5h://`；多个用逗号分隔轮换；未填会读环境变量 |
| 代理列表     | `proxies.txt`                                       | 每行一个代理 URL，`#` 开头为注释；与「代理」可同时使用       |
| 绕过         | `localhost,192.168.0.0/16`                          | 代理绕过列表，命中的主机直连；默认含 `localhost,127.0.0.1,::1`，另读 `NO_PROXY` 环境变量 |
| 扩展名列表   | `ext.txt`                                           | 字典里的 `%EXT%` 将展开为此文件中的扩展名；留空用内置默认 22 个 |

> 代理优先级：表单/文件 **优先于** 环境变量（`ALL_PROXY` > `HTTPS_PROXY` > `HTTP_PROXY`）。代理无协议前缀时按 `http://` 处理；认证内嵌于 URL（`user:pass@host:port`）。多代理下失败重试（重试次数 > 0）自动切换到下一个代理。

## 6. 实时输出解读

### 实时行格式

```text
[状态码] 完整 URL [响应大小] [-> 跳转目标 (附加说明)]
```

- **响应大小**：HTTP `Content-Length`（字节）；缺失显示 `-`。
- **跳转**：出现 `->` 表示 3xx，目标**同源**会自动入队并追加「（已加入扫描队列）」；跨域只标注不入队。

### 颜色对照

| 颜色   | 状态码       | 含义                                     |
| ------ | ------------ | ---------------------------------------- |
| 绿色   | 2xx          | 路径存在，重点关注的发现                 |
| 青色   | 3xx          | 重定向，会显示跳转目标                   |
| 黄色   | 4xx          | 客户端错误（403 / 404 / 405 等）         |
| 红色   | 5xx          | 服务器错误                               |
| 紫色   | `ERR`        | 请求失败（超时 / 连接失败 / DNS 错误等） |

> GUI 输出由引擎层剥离 ANSI 转义序列，**不会出现** `[33m` / `[0m` 这类残骸字符。

### 结束统计

```text
扫描完成，耗时 1.8s | 总请求: 15 | 2xx 发现: 3 | 重定向: 2 | 错误: 0
扫描完成，耗时 2.7s | 总请求: 4  | 2xx 发现: 2 | 重定向: 1 | 错误: 0 | 符合过滤并显示: 2
扫描完成，耗时 5.5s | 总请求: 2  | 2xx 发现: 1 | 重定向: 0 | 错误: 0 | 重试: 1
```

- 使用「仅显示」/「排除」时，末尾会附「符合过滤并显示: N」（**全量**计数不受影响）；
- 出现「重试: N」表示期间发生过的失败重试总数（重试成功的结果正常计入，不代表最终失败）。

## 7. 常见场景

| 场景                        | 填法                                                                                     |
| --------------------------- | ---------------------------------------------------------------------------------------- |
| 常规扫描                    | 目标 URL + 字典，其他留默认                                                              |
| 只看 200，滤除 404 噪音     | 「仅显示」填 `200`                                                                       |
| 关注 200/301/302/403        | 「仅显示」填 `200,301,302,403`                                                           |
| 只显示 2xx 与 3xx           | 「仅显示」填 `200-299,300-399`                                                           |
| 反向排除 404                | 「排除」填 `404`                                                                         |
| 组合：显示 2xx~4xx 但去 403 | 「仅显示」`200-499` + 「排除」`403,404`（排除优先）                                      |
| 高速内网扫描                | 并发 `100`，超时 `5`                                                                     |
| 低速隐蔽扫描                | 并发 `5`，超时 `30`                                                                      |
| 伪装浏览器 + 多 UA 轮换     | 高级 → User-Agent 填 `Mozilla/5.0 A,Mozilla/5.0 B`                                       |
| 带登录态扫描                | 高级 → Cookie 填 `SESSION=abc; TOKEN=xyz`                                                |
| Basic 认证保护的目标        | 高级 → Basic 认证 填 `admin:S3cr3t!`                                                     |
| 经 HTTP 代理扫描            | 高级 → 代理 填 `127.0.0.1:8080` 或 `http://user:pass@10.0.0.1:8080`                     |
| 经 SOCKS5 代理（如 `ssh -D`） | 高级 → 代理 填 `socks5://127.0.0.1:1080`                                              |
| 多代理轮换 + 失败切换       | 高级 → 代理 填 `http://10.0.0.1:8080,socks5://10.0.0.2:1080`，重试 `2`                  |
| 代理列表文件                | 高级 → 代理列表 选 `proxies.txt`，绕过 填 `*.internal.com,10.0.0.0/8`                   |
| 扫描扩展名备份              | 字典里写 `%EXT%`（见下节），扩展名列表留空即自动展开 22 个内置后缀                       |

## 8. 扩展名（%EXT%）展开

字典条目中出现字面量 `%EXT%` 时，扫描前会按扩展名列表自动展开为多条请求。

**示例字典：**

```text
admin.%EXT%
login.%EXT%
config.%EXT%
```

**默认（未填扩展名列表文件时）展开为内置 22 个后缀：**

```text
(空串 = 原路径), .html, .htm, .php, .php3, .php4, .php5, .phtml,
.asp, .aspx, .ashx, .asmx, .jsp, .jspx, .jspa, .cer,
.txt, .log, .bak, .old, .orig,
.gz, .tgz, .zip, .tar, .db, .sqlite, .mdb, .swp, .swo
```

**自定义扩展名文件**（`ext.txt`，每行一个，`#` 注释，前导点可省略）：

```text
# 常见 Web 后缀
.php
.asp
.jsp
.bak
.gz
.zip
```

启动日志会打印一条展开提示：

```text
[i] %EXT% 展开: 新增 4752 条（内置（22 个））
```
或
```text
[i] %EXT% 展开: 新增 800 条（自定义（ext.txt））
```

> **注意**：占位符未展开前，字面量 `%EXT%` 会被原样发给服务器（`%` 属于 URL 保留字符），多数服务器会返回 400 并附短响应。GUI/CLI 内核都会先展开再请求，不会出现这种残留。

## 9. 错误处理

GUI 中错误分两类显示：

- **启动/配置错误**：点「开始」后如果配置不合法，红色 `[!] ...` 行会出现在输出区顶端，扫描未启动。
- **运行时错误**：预检失败会红色 `[!] 目标 URL 不可达 ...` 并终止；单个请求失败记为紫色 `ERR`，不影响其余扫描。

| 错误信息                                                     | 原因                                            | 处理建议                                                     |
| ------------------------------------------------------------ | ----------------------------------------------- | ------------------------------------------------------------ |
| `请输入目标 URL`                                             | URL 字段为空                                    | 填 URL                                                        |
| `请选择字典文件`                                             | 字典字段为空                                    | 选一个存在的字典文件                                          |
| `无法读取字典文件 'xxx': ...`                                | 字典路径不存在或无权限                          | 检查路径是否正确                                              |
| `字典文件 'xxx' 为空或只包含注释`                            | 字典无有效条目                                  | 检查字典内容                                                  |
| `无法读取扩展名文件 'xxx': ...`                              | 扩展名文件路径错误                              | 检查路径或留空使用内置                                        |
| `扩展名文件 'xxx' 为空或只包含注释`                          | 扩展名文件无有效行                              | 每行至少一个扩展名（如 `.php` / `php`）                       |
| `无效的扩展名 'xxx'`                                         | 扩展名含非法字符                                | 只保留字母数字与 `. - _`                                      |
| `无效的目标 URL 'xxx': ...`                                  | URL 格式错误                                    | 检查拼写，需含 `http://` 或 `https://`                       |
| `无效的状态码过滤项 'xxx'`                                   | 「仅显示」表达式含非法字符或区间颠倒（如 `999-200`） | 使用 `200`、`200,301`、`400-499` 等合法形式                  |
| `无效的状态码排除项 'xxx'`                                   | 「排除」表达式含非法字符或区间颠倒              | 语法同「仅显示」                                              |
| `无效的认证凭据 'xxx'`                                       | Basic 认证缺少冒号或用户名为空                  | 使用 `user:pass` 格式                                        |
| `Cookie 含非法字符: ...`                                     | Cookie 值含 HTTP 头非法字符（中文、控制符）     | 使用合法的键值对                                              |
| `不支持的协议 'ftp'`                                         | 仅支持 http/https                               | 改用 http/https 地址                                          |
| `不支持的代理协议 'xxx'`                                     | 代理协议前缀不合法                              | 使用 `http://` `https://` `socks5://` `socks5h://` 或省略    |
| `无效的代理 'xxx': ...`                                      | 代理 URL 格式错误（端口/认证非法）              | 检查 URL 拼写与端口                                           |
| `无法读取代理文件 'xxx': ...`                                | 代理列表文件路径错误                            | 检查文件路径                                                  |
| `目标 URL 不可达: (代理) 连接失败: ...（已配置代理，请检查代理可用性）` | 代理本身不可达（预检逐个测试全部失败）          | 确认代理地址、端口、认证正确且代理进程在线                   |
| `目标 URL 不可达 (无法连接/超时): ...`                       | 预检失败，目标无响应                            | 确认目标在线、网络可达、端口正确                              |
| `[ERR] ... - 超时: ...`                                      | 单个请求超时                                    | 调大「超时」，或忽略个别慢路径                                |
| `[ERR] ... - 连接失败: ...`                                  | 连接被重置/拒绝                                 | 目标可能限流或防护，降低「并发」                              |
| `并发任务数必须 ≥ 1`                                         | 并发填了 0 或负数                               | 填 `1` 或更大                                                 |
| `超时（秒）必须 ≥ 1`                                         | 超时任非正整数                                  | 填 `1` 或更大                                                 |

## 10. 与 CLI 版本的差异

| 维度           | CLI (`dirscan.exe`)          | GUI (`dirscan-gui.exe`)                            |
| -------------- | ---------------------------- | --------------------------------------------------- |
| 入口形态       | 命令行参数                   | 表单 + 文件浏览按钮                                |
| 参数命名       | `-u / -w / -t / -T / ...`    | 表单字段（一一对应）                               |
| 结果输出       | 终端着色文本                 | GUI 日志区（自动剥离 ANSI，颜色由内核判断）        |
| 进度控制       | `Ctrl+C` 中断                | 「■ 停止」按钮                                     |
| 会话复用       | 每条命令独立                 | 窗口不重启可反复扫描，日志累积（点「清空」清屏）   |
| 脚本集成       | 适合 CI / Shell              | 适合桌面化手工评估                                 |
| 内核           | `dirscan` crate              | 同一个 `dirscan` crate（能力完全一致）             |

## 11. 构建与运行

### 直接运行（推荐）

下载发布包解压后双击：

- Windows 64 位：`dirscan-gui.exe`（无需安装依赖）

### 从源码构建

```powershell
# 安装 Rust 1.75+（https://rustup.rs）后执行：
git clone https://github.com/<你的用户名>/dirscan.git
cd dirscan

# GUI 二进制（包含 egui/winit 依赖）
cargo build --release --bin dirscan-gui
# 产物位于 target\release\dirscan-gui.exe

# 若同时需要 CLI
cargo build --release --bin dirscan
```

> GUI 需要图形环境；无头环境下请使用 CLI 版。
